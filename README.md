# NeoStats Data Engineering Internship Assessment

## Project Overview

This project focuses on building a retail sales data engineering pipeline using Python and Power BI. The datasets were cleaned, transformed, and analyzed to generate business insights and interactive visualizations.

## Technologies Used

* Python
* Pandas
* NumPy
* OpenPyXL
* Power BI

## Project Components

* Python ETL Pipeline
* Jupyter Notebook Workflow
* Cleaned Retail Dataset
* Power BI Dashboard
* Project Documentation

## Folder Structure

* Code → Python scripts and notebook
* Dataset → Raw datasets
* Documentation → Project report
* Output → Cleaned dataset
* PowerBI → Dashboard file
* Screenshots → Dashboard screenshots
